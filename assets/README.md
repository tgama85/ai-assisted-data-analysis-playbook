# Assets

Esta pasta é destinada aos recursos visuais do **AI-Assisted Data Analysis Playbook**.

## Finalidade

Pode armazenar, ao longo da evolução do projeto:

- banner/capa do NotebookLM;
- capturas da interface pública;
- diagramas da arquitetura;
- fluxos do processo de análise;
- imagens utilizadas no README ou em apresentações.

## Política de privacidade

Somente recursos visuais sem dados pessoais, credenciais, e-mails, fotos de perfil ou informações confidenciais devem ser versionados aqui.

Capturas contendo informações pessoais foram deliberadamente excluídas do escopo do repositório.

## Status atual

A identidade visual já é utilizada no NotebookLM público. Novos assets seguros podem ser adicionados futuramente conforme o projeto evoluir.

> Recursos visuais são complementares: a documentação metodológica e os resultados dos testes permanecem como fonte principal de rastreabilidade do projeto.
